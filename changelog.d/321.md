### Added

- The bottom of the dashboard sidebar shows which build is running: its version, commit, branch,
  and build time, with `-dirty` when it was built from uncommitted changes. The activity-bar
  view, the `[extension] activate` line in `runtime.log`, and `dist/build-info.json` in the
  installed extension carry the same stamp (#321)
- **AI Engineer Coach: What's New** opens the changelog, also from a link in the activity-bar
  view, with every change dated by the day it was merged. The first time a build with newer
  changes runs, a notification offers it; turn it off with the
  `aiEngineerCoach.showReleaseNotesAfterUpdate` setting (#321)
